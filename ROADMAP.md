# Openings roadmap

Openings makes technology jobs shared through public GitHub communities easier to find while preserving the original listing as the source of truth.

This roadmap shows the product direction, not fixed delivery dates. Priorities may change as community feedback and public data quality evolve.

## Now

- Publish the first stable web release with clear release notes.
- Expand and verify the public catalog of GitHub job communities.
- Publish transparent monthly snapshots about jobs, countries, and communities.
- Make the iOS and Android apps discoverable from the website when their store pages are ready.
- Improve contribution paths for source requests, content corrections, and first-time contributors.

## Next

- Offer reusable badges and README snippets for indexed communities.
- Improve curated job discovery across work models, technologies, and seniority levels.
- Expand translated product content and regional source coverage.
- Make community and author pages more useful to share outside Openings.

## Later

- Explore opt-in cross-device saved searches without weakening the privacy-first experience.
- Add more public data formats and integrations for researchers and community maintainers.
- Build sustainable community programs around source quality and contributor recognition.

## Shape the roadmap

Start a thread in [GitHub Discussions](https://github.com/openings-dev/web/discussions) for product ideas and questions. Use the [feature request form](https://github.com/openings-dev/web/issues/new?template=feature_request.yml) when the proposal is concrete enough to evaluate and track.
