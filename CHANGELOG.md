# Changelog

Notable changes to openings.dev are recorded here so candidates, community maintainers, and contributors can follow the product as it evolves.

This project follows [Semantic Versioning](https://semver.org/). Version tags publish categorized GitHub release notes automatically, while notable product changes are curated here.

## Unreleased

No unreleased changes yet.

## [0.1.0] - 2026-09-02

### Added

- Searchable jobs, communities, and author profiles sourced from public GitHub communities.
- Responsive discovery filters, saved jobs, comparisons, shareable searches, and curated discovery pages.
- Localized product UI and public documentation in English, Portuguese, Spanish, Italian, French, and German.
- Route-specific social cards, Atom feeds, monthly jobs reports, and a public synchronization status page.
- Privacy-first product telemetry, data-confidence details, and contributor pathways for source requests and corrections.
- Public roadmap, community sharing kit, issue templates, release automation, and continuous validation for `main`.

### Changed

- Narrow-screen discovery controls now keep secondary shortcuts inside the responsive filter panel.
- Full-site deployment is resumable in independent shell and job-page batches.
